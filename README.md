# exercicio-lista-2

Lista de exercícios 02 (Kotlin) — exercícios 12 a 20.

## Como executar
Abra a pasta no IntelliJ IDEA e rode `src/Main.kt`. Ele executa todos os exercícios em sequência.

## Estrutura
- `src/Main.kt` — ponto de entrada
- `src/exercicios/` — um arquivo por exercício (`Exercicio12.kt` … `Exercicio20.kt`)
- `src/model/` — classes usadas nos exercícios (`Pessoa`, `Produto`, `ContaBancaria`, `Funcionario`, `Gerente`)
